# GRAVETIDE — контекст проекта для Claude (сессии и агенты)

Этот файл читают все сессии Claude Code и все агенты из `.claude/agents`. В нём то, что нельзя вывести из кода:
- правила владельца;
- как здесь принято работать;
- где лежит план;
- планка качества визуала и интерфейса.

Подробные журналы всех этапов — в `docs/15`–`docs/21`. Передача между сессиями — `docs/HANDOFF_NEXT.md`; правила генерации — только по §2 этого файла.

## 1. Что это за игра
- **Жанр.** Онлайн-песочница про пиратов в стиле «Pirate Gothic». Мир показан **строго сверху**. Изометрия разрешена только в окне личного острова, а фигуры в бою — в ракурсе 3/4, как в HoMM3.
- **Цель владельца:** «очень сильно похоже на Heroes of Might and Magic 3, только пиратская»:
  - корабль — это армия из отрядов 7–8 уровней;
  - капитан — герой: первичные и вторичные навыки, книга приказов и пути, артефакты;
  - абордаж — пошаговый бой на гексах;
  - море — живая «карта приключений» в реальном времени: логова, стражи, отряды существ, дрейфы, боссы, Грааль.
- **Владелец — Дмитрий.** Говорит по-русски, ждёт коротких отчётов после каждой законченной части: что сделано, цифры, что осталось. Принимает решения сам, если они разумные. Спорное выносит в отчёт и работу не останавливает.

## 2. Правила владельца (жёсткие)
- **Арт — только из текущих ассетов.** Правило владельца от 2026-10-05: «надо обязательно делать все из текущих ассетов, нельзя делать через хигсфилд ничего, токены не трать».
  - **Никакой генерации:** ни Higgsfield (ни картинки, ни видео), ни других генераторов. Кредиты и токены не тратить.
  - Всё, чего нет, делать из того, что уже лежит в `assets/`: подкрасить, обрамить, собрать из частей, нарисовать кодом или CSS.
  - Без крови, скелетов, костей и черепов.
  - Если владелец когда-нибудь снова разрешит генерацию, стиль берётся только по домашним промтам из `docs/06_ART_DIRECTION.md` §17.4.
- **Карты и вход.** Капчу, Turnstile и вход в аккаунты не трогать — просить владельца. Учётные данные не вводить.
- **Git.**
  - После каждой законченной части: `npm run typecheck`, затем `npm test` (весь набор, около 3 мин), коммит и сразу пуш в `claude/fervent-noether-5bmdb8`.
  - Пушить **только** так:
    ```
    T=$(gh auth token --user antallusion) && B=$(printf 'x-access-token:%s' "$T" | base64 -w0) && git -c credential.helper= -c "http.https://github.com/.extraheader=Authorization: Basic $B" push -q origin claude/fervent-noether-5bmdb8
    ```
  - Деплоя нет.
- **Процессы.** Убивать только по PID: `netstat -ano | grep ":PORT .*LISTEN"`, затем `taskkill //PID <pid> //F`. **Никогда не трогать chrome.exe.**

## 3. Планка визуала и интерфейса (по жалобам владельца)
Он судит игру по скриншотам с телефона. **Главный экран — телефон боком (812×375, touch).** Проверять также 640×360, 800×450, 1280×720, 1440×900 и 375×812 (там показывается замок «поверните телефон»), на RU и EN.
- **Текст и цифры.** Не выходят за рамки, ничего не наезжает, ничего не обрезано. Кнопки не уходят под край карточки, то есть не требуют прокрутки, чтобы до них добраться.
- **Перевод.** Ни одной непереведённой строки, включая ответы админ-команд. Каждую русскую строку класть в `client/src/lang/*`; серверные строки — в `server.ru.*.ts` и в `TABLE` в `client/src/lang/server.ts`. Тесты проверяют русские словари на латиницу.
- **Бюджет всплывашек.**
  - Всё временное — тосты, реплики, баннеры, подсказки, карточки встреч и боссов, ленты — стоит только в верхней или нижней полосе, **никогда в центре**.
  - Все вместе занимают **не больше 15 %** площади экрана.
  - Проверять измерением: сумма прямоугольников ÷ площадь экрана и пересечение с центром. Глазами не проверять.
  - Длинное прячется за иконку сворачивания `#hud-fold` (список `FOLDED` в `client/src/ui/hud.ts`). По умолчанию свёрнуто.
- **Бой на телефоне.** Только поле с существами:
  - справа внизу — круглая кнопка книги;
  - слева внизу — круглые иконки действий;
  - текст только внутри книги;
  - карточка существа открывается тапом.
- **Арт на экране.** Ничего не растянуто, всё в своём масштабе. Ни один предмет не стоит на другом: корабль никогда не стоит на пирсе или суше. Флаги маленькие, примерно 0,6 ширины корпуса. Вместо букв-заглушек — настоящие иконки.
- **Окна снаряжения** — как «кукла» в WoW: портрет в центре, квадратные слоты по бокам.
- **Плавность.** Соседние корабли движутся плавно, без рывков.
- **Фильмы** играют **только** в шести местах:
  - выход из порта и заход в порт;
  - высадка на остров и уход с него;
  - успешный абордаж;
  - проигранный абордаж.

  При открытии вкладок и окон (таверна и т. п.) — никаких фильмов. Каждый фильм можно пропустить, он играет один раз и не съедает время хода в бою.
- **Выравнивание проверять числами** (`center()`, `audit()`). Скриншоты нужны для общего вида и текста, мелкие сдвиги на них не видно.

## 4. Стек, запуск, проверка
- **Стек.** Node 22 и TypeScript **без сборки**. Только «стираемый» синтаксис: нельзя `enum`, `namespace`, parameter properties. Импорты пишутся с `.ts`.
  - Сервер: `server/src/game/*.ts`, `Game.ts` крутится на 20 Гц.
  - Клиент: `client/src` — Canvas2D/WebGL и DOM-интерфейс.
  - Общие данные: `shared/src/data`. Протокол: `shared/src/protocol.ts` и `*proto.ts`.
- **Тесты.** `npm run check` = typecheck + тесты. Сейчас около 1117 тестов, 0 падений. Тесты на балансе — в `tests/balance`; лестница уровней D12 — канон.
- **Серверы:**
  - игра: `PORT=58521 node --disable-warning=ExperimentalWarning server/src/main.ts`;
  - проверочный с админ-командами: `PORT=58530 GRAVETIDE_ADMIN=1 DB_PATH=data/qa.db …` — конфиг `gravetide-admin` в `.claude/launch.json`.
  - Помощникам давать **свои** порты 586xx–587xx.
  - Фоновые задачи живут не больше 2 часов. Для постоянной игры владелец сам запускает `start.bat`.
- **Админ-команды** набираются в чате: `gravetide.net.send({t:'chat', text:'/…'})`, полный список — `/help`. Примеры:
  - `/level /silver /xp /glory /tp /ship /foe /board`
  - `/army /lair /stack /drift /zboss /seal /trial /seamark`
- **Отладка в браузере.**
  - `gravetide.open('port'|'ship'|…|null)` — открыть любое окно; сначала `open(null)`.
  - `gravetide.state`, `gravetide.hud`, `gravetide.renderer`.
  - Тестовый бой — `/?battle` или `/?battle=<логово>`.
- **Браузерная проверка.**
  - Headless Chromium: `createRequire('C:/Users/enosi/mobaudit/package.json')` → `playwright-core`; exe `C:/Users/enosi/AppData/Local/ms-playwright/chromium-1234/chrome-win64/chrome.exe`; аргументы `['--use-angle=swiftshader','--enable-unsafe-swiftshader']`; для телефона `isMobile: true, hasTouch: true`.
  - Набор QA: `await (0,eval)(await (await fetch('/assets/raw/qa.js?'+Date.now())).text())`, затем `center()`, `audit()`, `headAlign()`, `hudOverlap()`, `sweep([...])`.
  - Скрипты входа и боя — в `assets/raw/audit/*.mjs`. Папка `assets/raw/` в `.gitignore`: **не удалять worktree с несохранёнными скриптами**, они пропадут.

## 5. Как работать (проверено)
- **Помощники.**
  - Каждый — в своём worktree: `git worktree add ../pirates-X -b batch-X`, затем скопировать `node_modules` и `assets/raw/{qa,audit,center}.js`.
  - Одновременно не больше двух, на непересекающихся областях. Бой (`tacbattle.ts` / `client/src/ui/tactical.ts`) — только один из них.
  - Новые пункты давать **прямо в промте** нового помощника, а не досылать сообщением: досланное однажды приняли за подмену инструкций.
- **Слияние.**
  - Конфликты разбирать через `python assets/raw/audit/resolve3.py <files>` — трёхсторонний разбор по символам, при пересекающихся правках он падает. Старый `resolve.py` не использовать: он склеивает строки.
  - После слияния проверить таблицу `TABLE` в `server.ts`, `type Modal` в `main.ts` и импорты.
- **HELP админки.** Строка `HELP` в `server/src/game/admin.ts` и её русская пара в `client/src/lang/server.ru.admin.ts` совпадают команда в команду, это проверяет тест.
- **Детерминизм.**
  - У каждой новой случайной системы свой `Rng` — по образцу `ar()` в `server/src/game/auction.ts`, потому что тесты прогоняют общий `game.rng`.
  - Новые объекты мира только дописываются в конец (`legacyWorld`).
  - Время берётся из `game.wallNow()`. Тесты не привязывать к реальной дате.
- **Баланс.** Ориентиры:
  - доход — `seaHour(L)` в `tests/balance/island.ts`;
  - равный бой — около 50 %;
  - если бойцов на 10 % меньше, поражение в 65–75 % боёв;
  - обычный экипаж против пиратов своего уровня — 45–55 %.
  - Тик сервера — не больше 3 мс при 40 ботах.

  - **проверка:** `browser-qa`, `click-path-audit`, `e2e-testing`, `verification-loop`, `production-audit`, `workspace-surface-audit`;
  - **код и переводы:** `frontend-patterns`, `coding-standards`, `inherit-legacy-style`, `i18n-sync`, `codebase-onboarding`.
- **Агенты** (`.claude/agents`): `a11y-architect`, `typescript-reviewer`, `e2e-runner`, `performance-optimizer`, `code-reviewer`, `silent-failure-hunter`, `refactor-cleaner`, `code-explorer`, `planner`.
- **Как применять.** Скиллы общие и написаны под веб-приложения. В этом проекте **главнее правила §2–§3**:
  - мрачная палитра Pirate Gothic с насыщенностью до 35 % (`docs/06`);
  - стиль WoW / HoMM3, без «чистого» плоского веба;
  - бюджет всплывашек 15 %;
  - телефон боком на первом месте.

  Если совет скилла с ними расходится, побеждают правила проекта.

- **`i18n-sync`** — следить, чтобы RU и EN совпадали.
