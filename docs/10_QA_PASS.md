# Phase 12 — QA-проход по вёрстке и интерфейсу (рабочий список)

Требование владельца (2026-09-27): открыть все окна и состояния игры и проверить их как лид-QA-дизайнер — идеальная сетка, всё отцентровано, ничего не наезжает и не обрезано, тексты на русском и к месту (на телефоне — без клавиш).

Как проверяется каждый пункт: состояние воспроизводится на админ-сервере `gravetide-admin` (чат-команды `/tp`, `/boss`, `/weather`, `/time`, `/sink`… и `gravetide.open(окно)`), затем QA-набор `assets/raw/qa.js`:
`center()` — центровка каждой подписи и иконки в рамке по «чернилам» букв + ряды «иконка + текст»; `audit()` — переполнение, обрезка, наложения; `headAlign()` — крестик против таблички; `sweep([...])` — все вкладки окна с прокруткой до конца.
Форматы: 375×812 (телефон, тач), 768×1024 (планшет), 812×375 (телефон горизонтально), 1440×900 (десктоп). Плюс скриншот — ритм отступов, тексты, перевод.
После каждого пункта: `npm run typecheck` → `npm test` → коммит и пуш.

Статусы: `[ ]` не начато · `[~]` в работе · `[x]` готово.
