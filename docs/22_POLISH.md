# 22. Доводка визуала и интерфейса

Ветка `batch-pol`, 2026-10-05.
Тесты — `tests/polish.test.ts`.
Скрипты замеров — `assets/raw/audit/pol/`.

## Часть A — хвосты прошлого прохода

- **A1. Итог боя у логова.**
  - Добыча больше не режется внутренней прокруткой.
  - Итог в две колонки: слева потери, справа добыча.
  - Предложение «пойти за вами» — на всю ширину.
  - Внутренняя прокрутка: 32 px → 0 на всех пяти размерах, RU и EN.
  - Файл: `client/styles.css`.
- **A2. Проигрыш высадки в Первой вахте.**
  - Новичок получает людей обратно, как при буксире.
  - Тост: «Шлюпки Короны снимают ваших людей с берега».
  - Файлы: `server/src/game/beastlairs.ts`, `client/src/lang/server.ru.lairs.ts`.
- **A3. Пропуск фильма.**
  - Пропускается щелчком, касанием и любой клавишей.
  - Клавиша дальше не уходит — ни в игру, ни в окно под фильмом.
  - Подпись — в `client/src/lang/ui/film.ts`.
  - Файл: `client/src/ui/cutscene.ts`.
- **A4. Фильм поверх окна.**
  - Если открыто окно или фокус в поле ввода, фильм ждёт.
  - Через 20 с ожидания он отпускается и сыграет в следующий такой момент.
  - Окна самого момента — гавань, итог абордажа, крушение — не мешают.
  - Найдено и исправлено попутно: замок «поверните телефон» всегда лежит в странице и держал все фильмы. Теперь считается только видимый вопрос.
  - Файлы: `client/src/ui/cutscene.ts`, `client/src/main.ts`.
- **A5. Урок «Бой по ходам».**
  - Пушки урока оставляют рейдеру не меньше 7/10 людей (10 из 14).
  - Бой длится 3–4 раунда, ученик побеждает 20 из 20.
  - Файлы: `server/src/game/combat.ts`, `npc.ts`, `onboarding.ts`.

## Часть B — шлифовка

### Всплывашки
- Тост, который не влез в полосу, раньше переносился в столбец за её краем. Там он лежал под картой, меню или штурвалом.
- Теперь такой тост скрыт и показывается, когда уйдут те, что перед ним.
- Результат — `hudOverlap` = 0 на 640×360, 800×450, 1280×720 и 1440×900.

### Ощущение кнопок
- Есть нажатое, наведённое и недоступное состояние: `.btn`, вкладки, кнопки действий, плитки меню, слоты.
- Фокус с клавиатуры — золотое кольцо, при щелчке мышью его нет.
- На сенсоре цель пальца ≥ 40 px. Попадание расширено псевдоэлементом, вёрстка не сдвинулась ни на пиксель.
- Окно открывается мягко: прозрачность, 140 мс, без сдвига.
- `prefers-reduced-motion` гасит анимации везде.
- Цифры HUD, штурвала и боя — одной ширины, поэтому при смене чисел ничего не прыгает.

### Контраст
- Приглушённый текст: был `--steel` 3,4:1, стал `--steel-text` 5,2:1 на тёмном дереве. Правил — 6.
- Мелкие чернила книги на пергаменте доведены до ≥ 4,5:1. Правил — 4.

### Путь кликов (телефон боком, RU)
- Порт → «Поднять паруса» → проверка выхода → «Выйти»: 3 касания.
- Фильм выхода — плюс 1 касание.
- Абордаж → «…» → «Быстрый бой»: 2 касания.
- Итог → окно приза → «В порт»: 1 касание.
- Капитан → книга пути: меню → герой → вкладка, 3 касания.
- Тупиков нет.
- Все фильмы по пути (выход, порт, победа, заход) снимаются одним касанием.
