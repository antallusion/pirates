# 40 улучшений (владелец, 2026-09-30)

Без Higgsfield и любой генерации: только ассеты из `assets/`, процедурная отрисовка и механики игры. Каждое — сервер + клиент + RU/EN + тесты + проверка на 375×812, 812×375, 820×1180, 1440×900. Делаются партиями по 5 через луп; в журнале — коммит и цифры.

Статусы: `[ ]` не начато · `[~]` в работе · `[x]` готово.

## Партия A — бой и абордаж
- [ ] 1. Прицел по ветру: ядра сносит боковым ветром, метка падения показывает снос.
- [ ] 2. Критические попадания по частям корабля (руль, мачта, пороховой погреб) с понятной иконкой над целью.
- [ ] 3. Сдача в плен: побитый NPC спускает флаг — выбор «отпустить за выкуп / забрать груз / взять приз».
- [ ] 4. Серии побед: 3 потопленных подряд без захода в порт — бонус к добыче и опыту с растущим множителем.
- [ ] 5. Именные корабли-трофеи: взятый приз сохраняет своё имя и историю, её видно в карточке корабля.

## Партия B — море живое
- [ ] 6. Караваны NPC с охраной идут между портами по видимым маршрутам — цель для рейда или конвоя.
- [ ] 7. Пиратские логова на островах: крепость с батареями, штурм даёт сундук и карту.
- [ ] 8. Дуэли NPC между собой: патруль гонит пирата, игрок может вмешаться за любую сторону.
- [ ] 9. Стаи дельфинов и киты идут за кораблём — добрый знак: +мораль и ход на время.
- [ ] 10. Погода по фронтам на миникарте: видно, куда идёт шторм, можно обойти или поймать.

## Партия C — экономика и порт
- [ ] 11. Спрос портов на карте мира: иконки товаров «дорого/дёшево» у портов, по возрасту сведений.
- [ ] 12. Торговые поручения цепочкой: «купи здесь — продай там» с бонусом за скорость.
- [ ] 13. Аукцион трофеев в свободных портах: редкие вещи с таймером ставок, NPC-покупатели.
- [ ] 14. Таверна: слухи с реальными координатами клада или каравана за серебро.
- [ ] 15. Ремонт в море за доски и парусину из трюма (медленно), в порту — быстро за серебро.

## Партия D — команда и капитан
- [ ] 16. Имена и характеры у офицеров в диалогах: реплики при событиях (шторм, победа, голод).
- [ ] 17. Мораль видна на палубе: при низкой — ропот в тостах, при высокой — песня и бонус.
- [ ] 18. Навыки команды растут от дела: канониры от стрельбы, рулевые от походов.
- [ ] 19. Раненые после боя: лечит лекарь, без него часть гибнет; лекарства в трюме.
- [ ] 20. Капитанский журнал: автоматическая летопись дня с главными событиями.

## Партия E — острова и суша
- [ ] 21. Высадка с исследованием: 3–4 шага по острову с выбором тропы (из мини-игр).
- [ ] 22. Тайники игроков: закопать сундук и продать карту к нему другому капитану.
- [ ] 23. Маяки ведут ночью: зажжённый маяк показывает мели в радиусе.
- [ ] 24. Смотровые на мысах: высадка открывает карту округи на 5 км.
- [ ] 25. Сезонные острова: остров появляется в отлив/сезон и исчезает, на нём редкая добыча.

## Партия F — прогресс и цели
- [ ] 26. Карьера по фракциям: звания в Короне, Лиге, Братстве с наградами и доступом.
- [ ] 27. Еженедельные испытания с таблицей лидеров по регионам.
- [ ] 28. Коллекции: рыбы, чудеса, приметы, трофеи — альбом с наградой за полный набор.
- [ ] 29. Титулы над кораблём за подвиги («Гроза Лиги», «Друг китов»).
- [ ] 30. Возвращение после перерыва: сводка «что случилось без вас» и подарок.

- [ ] 32. Совместные мировые цели сервера с общей шкалой и наградой всем.
- [ ] 33. Обмен предметами между игроками рядом в море (без порта).
- [ ] 34. Гильдейская верфь на личном острове лидера: общий вклад ресурсов.
- [ ] 35. Сигнальные флаги: быстрые команды группе («за мной», «атакую», «нужна помощь»).
