# Phase 13 — «Офигенная MMO»: абордаж, динамичный бой, живые острова, ~3000 квестов (рабочий список)

Запрос владельца (2026-09-27): превратить проект в офигенную MMO — около 3000 квестов, куча экшена, более динамичные бои; система абордажа слабая — сделать привлекательной; острова красивее: разные биомы, острова случайно заселены. Токены API Higgsfield кончились — арт делать через браузерное расширение (Claude in Chrome) на сайте Higgsfield безлимитной моделью.

Что есть сейчас (опись 2026-09-27): 8 рукописных квестов + процедурные контракты трёх видов; бой — настоящие ядра, 7 видов критов, 24 способности капитанов, 20 активных талантов; абордаж решается сам по раундам (сила × боевой дух), игрок лишь выбирает режим клавишей до схватки и дележ после; 7 биомов по одному на регион, острова без жителей.

Правила: только стираемый синтаксис TS, импорты с `.ts`; каждая новая фраза сервера с русским переводом; `npm run typecheck` + `npm test` + проверка в браузере (телефон 375×812 тач, планшет, 812×375, десктоп; QA-набор `assets/raw/qa.js`) → коммит и пуш; процедурный запасной путь для любой графики. Процессы — только по PID.

Статусы: `[ ]` не начато · `[~]` в работе · `[x]` готово.
