# Phase 13 — «Офигенная MMO»: абордаж, динамичный бой, живые острова, ~3000 квестов (рабочий список)

Запрос владельца (2026-09-27): превратить проект в офигенную MMO — около 3000 квестов, куча экшена, более динамичные бои; система абордажа слабая — сделать привлекательной; острова красивее: разные биомы, острова случайно заселены. Токены API Higgsfield кончились — арт делать через браузерное расширение (Claude in Chrome) на сайте Higgsfield безлимитной моделью.

Что есть сейчас (опись 2026-09-27): 8 рукописных квестов + процедурные контракты трёх видов; бой — настоящие ядра, 7 видов критов, 24 способности капитанов, 20 активных талантов; абордаж решается сам по раундам (сила × боевой дух), игрок лишь выбирает режим клавишей до схватки и дележ после; 7 биомов по одному на регион, острова без жителей.

Правила: только стираемый синтаксис TS, импорты с `.ts`; каждая новая фраза сервера с русским переводом; `npm run typecheck` + `npm test` + проверка в браузере (телефон 375×812 тач, планшет, 812×375, десктоп; QA-набор `assets/raw/qa.js`) → коммит и пуш; процедурный запасной путь для любой графики. Процессы — только по PID.

Статусы: `[ ]` не начато · `[~]` в работе · `[x]` готово.

## P1 — Абордаж 2.0 (главная жалоба)
- [ ] **Живая схватка на палубе**: пока крючья держат, поверх экрана — окно абордажа: две полосы сил и духа, счётчик раундов, лента событий («Картечь с юта выкосила шестерых»), портреты капитанов; на телефоне — крупные кнопки внизу.
- [ ] **Тактика каждый раунд** (сервер ждёт выбор ~4 с, иначе «держать строй»): залп мушкетов / рукопашная / гранаты / удержать шкафут / охота на офицеров / сорвать флаг — «камень-ножницы-бумага» против стойки врага (ИИ выбирает по характеру и потерям), с явной подсказкой, что бьёт что.
- [ ] **Импульс**: удачные раунды копят натиск; полный натиск открывает приём капитана (свой у каждого из 6 архетипов) и офицеров.
- [ ] **Дуэль капитанов** как кульминация: вызов по кнопке, 3 обмена ударами на тайминг (тап в окно), итог решает схватку.
- [ ] Звук и анимация: брызги, крики, лязг, дым; итоговое окно — «Приз» с отчётом схватки.
- [ ] Тесты: раунд без выбора, камень-ножницы-бумага, дуэль, выход по тросам, ИИ.

## P2 — Динамичный бой
- [ ] **Прицел с зарядом**: удержание кнопки борта показывает дугу залпа и «идеальное окно» (выстрел в окне — кучнее и сильнее); на тач-кнопках — удержание вместо тапа.
- [ ] **Рывок/уклонение**: короткий манёвр (резкий поворот + ускорение) с откатом; уклонение от залпа, если вовремя.
- [ ] **Слабые места**: продольный огонь с кормы/носа подсвечивается, крит-зоны по положению цели; попадания с цифрами, отметкой и тряской.
- [ ] **Тактика ИИ**: волчьи стаи (2–3 пирата заходят с разных бортов), патрули в строю, отход и засада в тумане, торговцы бросают груз.
- [ ] **События боя**: огненные брандеры, порох на палубе, пожары, мачты за борт как тактический выбор.
- [ ] Баланс и тесты боёв.
