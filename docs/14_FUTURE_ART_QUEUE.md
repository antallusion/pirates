# GRAVETIDE — очередь будущего арта (по факту на 2026-09-29)

Прежняя версия этого файла перечисляла «батчи 8–16» (товары `good_*`, жители `resident_*`, памятники, перки, рыбалка, караваны, именные пираты). Большая часть этих id игрой не запрашивается, а товары, рыба, татуировки и портреты жителей давно нарисованы под своими настоящими id (`icon.good_*`, `icon.fish_*`, `icon.tattoo_*`, `portrait.res_*`). Листы-пустышки `goods_1`, `residents_2`, `monuments_1`, `perks_1`, `fishing_1` убраны из `tools/art/sheets.json`.

Правило: новые id берутся только из кода и данных. Найти настоящие дыры:
- `npx tsx assets/raw/art_cover.ts` — покрытие семейств;
- `python assets/raw/art_missing.py` — id из кода, которых нет в манифесте;
- заглушки `STAND_IN` и `PORTRAIT_STAND_IN` в `client/src/ui/dom.ts`.

## Мировой арт, нарисованный не сверху (аудит 2026-09-29)

По канону (docs/06 §0, §16 п. 1) всё на карте — строго сверху. Сейчас с наклоном 3/4 или сбоку нарисованы и уже стоят в игре:
- `prop.port_*` (8);
- `prop.lighthouse`, `prop.bell_tower`, `prop.volcano`, `prop.spring`, `prop.hermit`, `prop.mine`, `prop.shipwreck`, `prop.life_hut`;
- спорные: `prop.fort`, `prop.bones`, `prop.shrine`, `part.fire`, `part.muzzle`.

Решение владельца: не перерисовывать. Корабли, твари, текстуры, декор биомов, флаги и частицы (кроме двух спорных) — сверху. Листы аудита: `assets/raw/audit/` (не в git).
