# Phase 11 — Art & UI pass (рабочий список)

Требования владельца (2026-09-26): весь визуал — через Higgsfield; интерфейс игровой, «как в WoW, но в нашем стиле»; **mobile-first**, ничего не накладывается, всё чётко на телефоне, планшете и десктопе; управление с клавиатуры и тача обязано работать; игра не должна лагать.

Правила: процедурная отрисовка остаётся запасным путём; после каждой задачи — typecheck → `npm test` → проверка в браузере (мобильный 390×844, планшет 820×1180, десктоп 1440×900) → коммит.
Пайплайн ассетов: `tools/art/register.py` + `tools/art/process.py` (см. шапку файлов), сырьё в `assets/raw/` (не коммитится).

Статусы: `[ ]` не начато · `[~]` в работе · `[x]` готово.

## P0 — играбельность
- [x] **Управление с клавиатуры** — причина: клавиши сравнивались по символу (`e.key`), и при русской раскладке WASD давали «цфыв». Теперь `keyOf()` берёт физическую клавишу (`e.code`); тест в `tests/settings.test.ts`.
- [x] **Сенсорное управление** (`client/src/touch.ts`) — штурвал-стик задаёт курс и держит его, ступени парусов, залпы бортов с автонаводкой, погонные, палубная установка, кнопка действия (абордаж, порт, высадка), тап по морю — точка прицела, щипок — зум, меню «Каюта капитана».
- [x] **Лаги** — ассеты в WebP под игровые размеры (100 МБ → 11 МБ); `art.reference_captain` не грузится; панель способностей больше не пересобирается каждый кадр (перезарядка и откаты — на месте); подсказка/регион пишутся только при изменении; миникарта 8 Гц, компас 15 Гц; без `backdrop-filter` в HUD; DPR ≤ 1.5 на тач-устройствах.

## P1 — mobile-first интерфейс в стиле «WoW × Pirate Gothic»
- [x] UI-кит из Higgsfield (`ui.*`, CSS-переменные через `ui/skin.ts`): рамка панели (9-slice), заголовок-плашка, кнопка-баннер, кнопка обычная, слот иконки, круглая оправа иконки, кнопка закрытия, рамка портрета, рамка миникарты с розой ветров, полосы корпуса/парусов, фон панели способностей, вкладки.
- [x] Каркас раскладки HUD (юнит-фрейм, круглая миникарта, стопки сверху и снизу, панель способностей со слотами, микро-меню). Наложений нет — проверено скриптом пересечений на 375×812, 740×360 (тач), 820×1180, 1440×900: зоны безопасности (safe-area), портрет капитана с полосами сверху слева, миникарта сверху справа, панель способностей и боеприпасов снизу, цели/подсказки без наложений; брейкпоинты телефон-портрет / телефон-альбом / планшет / десктоп.
- [x] Модальные окна на новом ките (рамка, плашка, кнопки, вкладки с иконками, крестик); на телефоне — полноэкранные листы, рынок — карточки.
- [x] Экран порта: шапка с рисованной гаванью фракции и гербом, вкладки с иконками.
- [x] Экран выбора капитана, гибели, пролог, абордаж, каюта — рисованные фоны (`bg.*`).
