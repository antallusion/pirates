# «Герои» на море — GRAVETIDE по образцу Heroes of Might and Magic III (владелец, 2026-09-30)

«Упор на механики как в Heroes of Might and Magic 3, только пиратская; абордаж можно сразу начинать; урон по кораблю ранит бойцов с обеих сторон; всю логику завязать на абордаже».

Главное решение: **корабль — это армия, капитан — герой, абордаж — бой.** Плавание по морю остаётся в реальном времени (как «карта приключений», только живая), всё остальное устроено как в «Героях»: отряды с числом бойцов, найм в «жилищах» с приростом по неделям, герой с первичными навыками и выбором вторичных на уровне, книга приказов (заклинаний) с «волей» (маной), артефакты, ресурсы и шахты, объекты на карте, охраняемые нейтральными отрядами.

Арт — только то, что есть в `assets/` (портреты, `icon.prof_*`, `icon.role_*`, `icon.item_*`, `icon.ab_*`, `icon.build_*`, `icon.good_*`, `prop.*`, `ship.*`), процедурная отрисовка и CSS. Higgsfield и любая генерация запрещены.

Статусы: `[ ]` не начато · `[~]` в работе · `[x]` готово.

- [x] 2. **Урон по кораблю бьёт по отрядам с обеих сторон.** Залпы, картечь, пожары и крики-пробоины убивают бойцов в отрядах (картечь — больше всего; ядра — меньше), с учётом защиты; обе стороны теряют людей до абордажа; корпус корабля — это «стены» (защита отрядов), а не главное. — *сделано:* ядро убивает людей по уязвимости отрядов (хп и защита, относительно обычного состава её вод — темп пушечного боя D12 не сдвинут), корпус = стены (×0,65 через целый борт → ×1,35 через разбитый; пробоины — это дыры в стене), картечь бьёт по открытой палубе без стен (2,4 чел. за попадание против 0,33 у ядра по целому корпусу), пожар — ~1 человек из 250 в секунду; всплывающее «−N чел.» — одно число на залп; работает и NPC против NPC. *Не сделано:* отдельная смерть людей от течи (давала сдвиг в симуляции «трое против одного»).
- [x] 3. **Абордаж сразу.** Сцепиться можно с любого корабля в пределах досягаемости крючьев (без требования «сначала разбить»); бой открывается на поле из текущих отрядов обеих сторон, повреждения корабля дают штрафы/бонусы (пробоины = препятствия, разбитые пушки, пожар на палубе). — *сделано:* требование «сначала разбить» снято, допуск разницы скоростей 5,5→8 уз, лестница уровней D12 остаётся; поле строится из отрядов обеих сторон: пробоины (по потерянному корпусу и течам, до 4) — непроходимые гексы, пожар — горящие гексы (10% силы отряда в начале его хода), разбитые пушки — у канониров меньше зарядов и слабее удар. **3b.** Затонувший NPC отдаёт 25% трюма (было 40%) и 30% казны (было 50%), опыт: потопил 40 (было 45), взял абордажем 90 (было 70); NPC-пираты идут на абордаж сразу, если их армия сильнее в 1,3 раза, иначе бьют картечью.

- [x] 5. **NPC-корабли — тоже армии** с отрядами по уровню сектора; сила армии («Их немного / много / орда») видна в карточке цели, как в «Героях». — *сделано:* армия NPC — по уровню корабля из сектора и роли (торговец, пират, флот, Хор/призраки с утопленниками, босс); сила на человека ⚓1 9,9 → ⚓4 19 → ⚓7 32 → ⚓10 62; карточка цели: «Горстка/Несколько/Группа/Много/Толпа/Орда/Тьма» (1/5/10/20/50/100/250) с диапазоном и лицами отрядов.
